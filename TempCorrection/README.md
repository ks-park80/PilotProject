# ☢️ 스펙트럼 분석 및 온도 보정 프로그램 (Spectrum Analyzer)

이 프로그램은 방사선 검출기 등의 스펙트럼 데이터와 온도(ADC) 데이터를 엑셀 파일로부터 불러와, **온도 변화에 따른 피크 채널(Peak Channel)의 이동을 분석하고 보정식을 산출**하는 Python GUI 도구입니다.

## 📌 주요 기능

* **엑셀 데이터 로드**: 대용량 스펙트럼 및 온도 로그 데이터를 스레딩을 통해 비동기로 로딩
* **데이터 시각화**:
    * **상단 그래프**: 시간(Interval)에 따른 온도(Temp ADC) 변화 그래프
    * **하단 그래프**: 2048 채널 스펙트럼 그래프 (ROI 설정 및 확대/축소 지원)
    * **우측 그래프**: 온도(Temp ADC) vs 피크 채널(Peak CH) 회귀 분석 그래프
* **자동 피크 검출**: Savitzky-Golay 필터 및 Gaussian 스무딩을 적용하여 노이즈를 제거하고 피크를 자동 검출
* **분석 도구**:
    * **ROI(관심 영역) 설정**: 스펙트럼의 특정 구간을 지정하여 정밀 분석
    * **다항식 회귀 분석**: 2차~6차 다항식을 선택하여 온도에 따른 피크 이동 경향성 수식($R^2$ 포함) 산출
    * **채널 오차 계산**: 기준값(Ratio × chpeak_b) 대비 오차율 계산
* **결과 저장**: 분석된 데이터 테이블, 회귀 수식, 그래프 이미지를 엑셀 파일로 저장
