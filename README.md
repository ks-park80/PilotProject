# ☢️ 1D CNN 기반 자동 핵종 분석(RIID) 시스템

본 프로젝트는 NaI(Tl) 검출기의 온도 변화(-20°C~50°C)로 인한 피크 이동(Peak Drift) 현상을 극복하기 위해 개발된 **딥러닝 기반 핵종 식별 시스템** 개발을 위해서 작업하는 공간입니다.

* **핵심 목표**: 온도 보정 없이도 환경 변화에 강건한 경량화된 핵종 분석 모델 개발 및 임베디드 장비 탑재
* **데이터 처리**: 2048채널 원시 스펙트럼 로그 파싱, 1024채널 리빈(Re-binning), Min-Max 정규화 수행
* **강건성 확보**: 데이터 부족 해결 및 일반화 성능 향상을 위해 가우시안 노이즈 및 채널 시프트(Channel Shift) 증강 기법 적용
* **모델 구조**: 임베디드 환경을 고려하여 Global Average Pooling을 적용한 **경량 1D-CNN 아키텍처** 설계
* **신뢰성**: CPS 임계값이 아닌 실험 설계 기반의 Ground Truth 라벨링을 통해 데이터 무결성 확보
* **개발 환경**: Python, TensorFlow/Keras, Google Colab
