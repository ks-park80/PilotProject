# ☢️ GM/PIN CPS 분석기 (Doserate Analysis GUI)

엑셀 파일에 기록된 방사선 센서(GM/PIN)의 CPS 또는 선량률(Doserate) 데이터를 시각화하고, 특정 구간의 평균값을 분석하여 리포트로 저장하는 Python GUI 프로그램입니다.

## 📌 주요 기능

* **엑셀 데이터 로딩**: `.xlsx` 또는 `.xls` 파일을 불러와 **G열(7번째 열)**의 데이터를 자동으로 파싱합니다.
* **데이터 시각화**:
    * Matplotlib을 이용한 시계열 산점도 그래프 출력
    * **Log / Linear 스케일** 전환 지원
    * 줌(Zoom) 및 이동(Pan) 기능 지원
* **구간 평균 분석**:
    * 그래프상의 특정 지점을 클릭하여 분석 포인트 지정
    * 슬라이더를 이용해 **평균 계산 범위(Window Size)** 실시간 조절
    * 선택된 구간 시각화 (녹색 박스) 및 실시간 평균값 테이블 표시
* **결과 리포트 저장**:
    * 분석된 포인트와 평균값을 엑셀 파일로 저장
    * 현재 분석 중인 그래프 이미지를 캡처하여 **엑셀 시트에 자동 삽입**
